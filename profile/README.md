# Project H2O

Project H2O is an emulation project for the arcade racing game, H2Overdrive.

Built on OpenParrot, Project H2O aims to be the definitive way to experience H2Overdrive at home.

### [View Info](https://github.com/ProjectH2O/ProjectH2O) and [Download Here](https://github.com/ProjectH2O/ProjectH2O/releases/latest)

### Components

- [OpenParrot-H2O](https://github.com/ProjectH2O/OpenParrot) - a fork of OpenParrot with numerous H2Overdrive-specific enhancements
- [TeknoParrotUI-H2O](https://github.com/ProjectH2O/TeknoParrotUI) - a fork of TeknoParrotUI designed for OpenParrot-H2O
- [H2ODashboard](https://github.com/ProjectH2O/H2ODashboard) - a virtual dashboard for H2Overdrive that emulates the one found on the arcade cabinet
